# Extreme Rainfall Modeling using Extreme Value Theory

## Project Overview

This project was carried out during my research position at CCR (Caisse Centrale de Réassurance).

The objective is to model extreme rainfall events (Cévenol episodes) using Extreme Value Theory for natural catastrophe risk assessment.

---

## Data

- DRIAS climate projections
- ALADIN numerical model
- Météo-France / CNRM

---

## Methodology

- Data preprocessing
- Block Maxima (GEV)
- Peaks Over Threshold (GPD)
- Model comparison

---

## Technologies

- R
- Extreme Value Theory
- Climate modelling
- Statistical modelling

---

## Results

The models estimate the occurrence and intensity of extreme rainfall events under future climate scenarios.
